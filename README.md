# Alchemist · 원자의 실험실

원자를 연결하고 60종의 분자를 발견하는 한국어 화학 구조 퍼즐입니다.

- 118개 원소 소환, 드래그로 결합, 분자 완성 시 각도 정돈
- 회전·확대 가능한 3D 모형, 단계별 힌트, 물리·화학 설명
- 작은 소환·발견 효과음, 원자·분자 삭제, 조합대 전체 비우기
- 발견한 도감과 효과음 설정은 각 방문자의 브라우저에 저장

공개 주소: https://nocomp299.github.io/ — GitHub Pages 게시가 활성화된 후 이용할 수 있습니다.

## 게시 설정

Settings → Pages → Source: Deploy from a branch → main → /(root) → Save.
이 저장소에는 이미 빌드된 정적 파일이 들어 있으므로 별도 빌드나 API 키가 필요하지 않습니다.

## 저장과 모형의 범위

같은 브라우저와 주소에서 도감이 유지됩니다. 다른 기기와 동기화되지 않으며, 사이트 데이터 삭제나 시크릿 모드 종료 시 기록이 사라질 수 있습니다. 작업대 자체는 새로고침하면 비워집니다. 기존 비공개 사이트의 계정별 기록은 포함하지 않습니다.

등록된 중성 공유 결합 분자의 연결 구조를 인식하는 교육용 퍼즐입니다. 일부 실측 각도를 제외한 입체 모형은 근사이며 실제 반응·전자 분포·이온 결정은 재현하지 않습니다.

TypeScript 검사, 정적 빌드, 화학 모델·도감 저장에 대한 19개 자동 검사를 통과한 배포본입니다.
