# Alchemist · 원자의 실험실

[게임 플레이](https://nocomp299.github.io/)

한국어 화학 구조 퍼즐입니다. 상단에서 **공유 결합**과 **이온 결합** 실험을 전환합니다.

- 공유 결합: 118개 원소 소환, 75종 분자 인식, 각도 정돈, 3D 모형과 단계별 힌트
- 이온 결합: 기본 단원자 이온 9종, 화합물 10종, 전하·조성비 검사와 이온 도감
- NaCl, KCl, LiF, MgO, CaO, Na₂O, MgCl₂, CaCl₂, CaF₂, Al₂O₃ 지원
- NaCl의 반복 결정 격자 일부를 회전해 보기. 다른 이온성 화합물은 조성 비율 모형으로 표시
- 구조 이성질체 15종 추가, 같은 분자식의 다른 연결 구조 찾아보기
- 등록된 물질의 반복 발견 팝업 제거, 발견 후 도감 카드 가운데 이동·강조
- 실제 시료 사진 15종과 출처·이용 조건 표시
- 효과음, 소환·묶음 삭제·전체 비우기, 브라우저에 도감 자동 저장

이온성 화합물의 화학식은 이온의 비율이며 독립된 분자를 뜻하지 않습니다. 점선은 작업대의 묶음 표시입니다. 실제 반응 조건·에너지·다원자 이온·여러 산화수는 이번 버전에 포함하지 않습니다.

## 저장

기존 분자 도감은 그대로 유지하며 이온 도감은 별도 키에 저장합니다. 같은 브라우저와 주소에서 기록이 유지됩니다. 기기 간 동기화는 없으며 사이트 데이터 삭제나 시크릿 모드 종료 시 기록이 사라질 수 있습니다. 작업대 자체는 새로고침하면 비워집니다.

## 소스와 개발

`source/`에 수정 가능한 소스와 테스트가 있습니다. Node.js 24 이상과 pnpm 11.25.0으로 실행합니다.

```sh
cd source
pnpm install --frozen-lockfile
npm run dev
npm test
npm run build
```

빌드 후 `source/dist/` 내부 파일을 저장소 루트에 반영하면 GitHub Pages가 게시합니다. 루트는 이미 빌드된 정적 파일이므로 API 키나 서버가 필요하지 않습니다.

## 확인 범위

TypeScript 검사, 프로덕션 빌드와 38개 자동 검사를 통과했습니다. 화학 모델, 전하 비율, 저장 재로딩, 기존 도감 보존과 저장 실패 처리를 검사했습니다. 신규 이성질체, 재발견 팝업 억제와 스크롤 위치 계산도 검사했습니다. 실제 브라우저 드래그·오디오·자동 스크롤 애니메이션·외부 사진 로딩은 이 개발 환경에서 직접 확인하지 못했습니다.

사진은 Wikimedia Commons에서 불러오므로 인터넷 연결이 필요합니다. 실물 사진은 현재 15종에 연결했으며, 확인된 사진이 없는 물질은 준비 중으로 표시합니다. [사진별 촬영자와 이용 조건](source/PHOTO-CREDITS.md)을 확인하세요. R/S·시스/트랜스 입체 이성질체는 별도로 구분하지 않습니다.
