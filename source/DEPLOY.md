# Alchemist를 GitHub Pages로 공개하기

GitHub Pages는 HTML·CSS·JavaScript로 만든 게임을 웹 주소로 공개하는 기능입니다. 이 배포본은 서버와 로그인 없이 실행되며, GitHub Free의 **공개(Public) 저장소**로 배포할 수 있습니다. 방문자는 GitHub 계정 없이 플레이할 수 있습니다.

## 필요한 파일

- **Alchemist-GitHub-Pages.zip**: 바로 업로드할 완성본. 설치나 빌드가 필요 없습니다.
- **Alchemist-Source.zip**: 나중에 게임을 수정할 때 사용하는 소스. 처음 배포할 때는 업로드하지 않아도 됩니다.

## 처음 배포하기 — PC에서 진행 권장

1. [GitHub](https://github.com/)에 가입하거나 로그인합니다. 이메일 인증을 마칩니다.
2. 오른쪽 위 **+ → New repository**를 누릅니다. 이름은 `alchemist`, 공개 범위는 **Public**으로 정합니다. README 추가를 선택하고 **Create repository**를 누릅니다. 이미 같은 이름의 저장소가 있다면 다른 이름을 사용해도 됩니다.
3. **Alchemist-GitHub-Pages.zip의 압축을 해제**합니다.
4. 저장소에서 **Add file → Upload files**를 누릅니다. 압축을 푼 폴더 *안의* `index.html`, `favicon.svg`, `assets` 폴더 등을 함께 끌어다 놓고 **Commit changes**로 저장합니다. ZIP 자체나 바깥 폴더를 통째로 올리지 마세요. 저장소 첫 화면에 `index.html`이 바로 보여야 합니다.
5. 패키지에는 빈 `.nojekyll` 파일도 들어 있습니다. 숨김 파일이라 업로드에서 빠졌다면 **Add file → Create new file**에서 이름을 `.nojekyll`로 지정하고 내용 없이 저장합니다. 이 파일은 이미 빌드한 게임 파일을 그대로 게시하도록 알려줍니다.
6. 저장소의 **Settings → Pages**로 이동합니다. **Build and deployment**에서 아래와 같이 선택한 뒤 **Save**를 누릅니다.

   | 항목 | 선택할 값 |
   | --- | --- |
   | Source | Deploy from a branch |
   | Branch | main |
   | 폴더 | /(root) |

7. 게시 작업이 완료되면 같은 Pages 화면의 **Visit site**로 게임을 엽니다. 작업 상태는 저장소의 **Actions**에서도 확인할 수 있습니다. `https://깃허브아이디.github.io/alchemist/` 형태의 주소를 친구에게 보내면 됩니다. 이것은 주소 형식 예시이며, 실제 주소는 Pages 화면에 표시됩니다.

공식 절차: [GitHub Pages 게시 소스 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 도감은 어디에 저장되나요?

발견한 분자와 최초 발견 시각을 **플레이한 브라우저의 사이트 저장 공간**에 보관합니다. 같은 주소를 같은 브라우저로 다시 열면 도감을 불러옵니다. 효과음 설정도 브라우저에 저장합니다.

- 로그인이나 다른 기기와의 자동 동기화는 없습니다.
- 사이트 데이터를 삭제하거나 시크릿 모드를 닫으면 도감이 사라질 수 있습니다.
- 기존 비공개 사이트의 계정별 도감은 자동으로 옮겨오지 않습니다. 공개판에서는 새 도감으로 시작합니다.
- 주소의 도메인이나 저장소 이름을 바꾸면 이전 주소에 저장된 도감을 자동으로 불러오지 못합니다.
- 조합대에 올린 원자와 결합은 새로고침하면 비워집니다. 발견한 도감은 남습니다.
- 저장이 차단되거나 공간이 부족하면 화면에 오류와 재시도 버튼을 표시합니다. 저장 대기 중에는 창을 닫지 말고 사이트 저장 설정을 확인해 주세요.

## 포함한 게임 기능

118개 원소 소환, 원자 드래그·결합, 60종 분자 인식, 완성 후 각도 정돈, 3D 회전·확대, 단계별 힌트, 물리·화학 설명, 소환·발견 효과음, 분자 단위 삭제와 조합대 전체 비우기를 포함합니다. 등록되지 않은 분자를 인식하지 못한다고 해서 실제로 존재하지 않는다는 뜻은 아닙니다. 입체 모형은 일부 실측 각도를 제외하면 교육용 근사입니다.

## 확인한 범위

TypeScript 검사, 정적 배포 빌드, 19개 자동 검사를 통과했습니다. 분자 인식과 이성질체 구분, 각도·3D 좌표, 단계별 힌트, 분자 삭제, 저장 후 다시 읽기, 중복 발견의 최초 시각 유지, 저장 실패·손상 데이터 보호를 검사했습니다. 배포 파일의 상대 경로와 참조 파일 존재 여부도 확인했습니다.

**실제 GitHub 저장소 업로드와 공개 배포는 아직 수행하지 않았습니다.** 이 환경에서는 화면 드래그와 소리 재생을 실제 브라우저에서 확인하지 못했습니다. 게시 후 물을 만들고, 새로고침했을 때 도감에 남는지 확인해 주세요. 휴대폰에서도 원자 드래그와 효과음 버튼을 한 번 확인해 주세요.

## 화면이 안 열릴 때

- **404**: Pages 설정이 `main`과 `/(root)`인지, 저장소 루트에 `index.html`이 있는지 확인합니다. 게시 작업 완료 후 다시 엽니다.
- **빈 화면 또는 모양이 깨짐**: `assets` 폴더와 그 안의 파일까지 함께 업로드했는지 확인합니다.
- **효과음이 안 남**: 화면을 한 번 누르고 스피커 설정의 ‘소리 들어보기’를 눌러 봅니다. 브라우저는 사용자 조작 전에 소리 재생을 제한할 수 있습니다.
- **도감이 저장되지 않음**: 시크릿 모드, 사이트 데이터 차단, 저장 공간 부족 여부를 확인합니다.

## 수정한 버전으로 업데이트하기

소스 ZIP의 README를 따라 수정하고 빌드한 뒤, 새 `dist` 폴더 안의 파일을 저장소 루트에 올립니다. `index.html`과 새 `assets` 파일을 함께 업데이트하세요. 오래된 `assets` 파일은 남겨 두어도 됩니다. 같은 도메인과 경로, 저장 키를 유지하면 브라우저의 기존 도감을 계속 사용할 수 있습니다.

공식 서비스 설명·무료 이용 범위: [GitHub Pages란?](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)
